### Step-by-Step Refactoring Advice

1. **State Migration to React:** Convert the raw JavaScript object arrays (`state`, `containerWidths`, `vOffsets`) into proper React hooks (`useState` or a structured `useReducer`) within your new component to prevent manual element updates via `document.getElementById`.
2. **Handling Pointer Events:** The custom interaction system (combining touch thresholds, pointer gestures, vertical vs horizontal drag mode selection, and variable snap behaviors) can be neatly wrapped into a custom React hook (e.g., `useFractionDrag`). This keeps the layout components completely separated from the complex math equations and positioning logic.
