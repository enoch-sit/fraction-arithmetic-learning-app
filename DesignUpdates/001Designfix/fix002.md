# Fix 002: Equivalent Fractions - Input Box Not Functional

## Problem Description
The app 「相等分數(約分/擴分)」 has issues with UI design and functionality:
- Users are unable to use or change the input number box
- Input controls are not responding

## Current State
- Input number boxes are non-interactive
- Users cannot modify fraction values
- Core functionality of the app is broken

## Affected Files
- `src/apps/equivalent/App.tsx`
- `src/apps/equivalent/app.css`
- `src/shared/components/FracInputStepper.tsx` (if used)

## Reference
- Original working version: `FractionApp64(相等分數).html`

## Root Cause Analysis
Possible causes:
1. Event handlers not properly attached to input elements
2. State management not updating input values
3. CSS z-index or pointer-events blocking interaction
4. Component disabled or in read-only mode

## Proposed Solution

### 1. Fix Input Interactivity
- Ensure onChange handlers are connected
- Verify state updates propagate correctly
- Check for CSS that might block pointer events

### 2. Add Input Validation
- Ensure inputs accept valid number ranges
- Provide user feedback for invalid inputs

### 3. Ensure Stepper Buttons Work
- Up/down arrows should increment/decrement values
- Validate min/max bounds
