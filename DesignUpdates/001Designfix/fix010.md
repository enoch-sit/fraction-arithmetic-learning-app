# Fix 010: Incorrect Bar Should Not Disappear After Clicking Other Buttons

## Problem
In the app 「異分母分數加法」, the incorrect bar should not disappear after clicking other buttons.

## Affected Apps
- Addition (異分母分數加法)

## Current State
When user makes an incorrect attempt:
- Incorrect bar is displayed
- But disappears when clicking other buttons/controls
- User loses context of their error

## Expected Behavior
The incorrect bar should:
- Remain visible until explicitly cleared
- Persist across other UI interactions
- Only disappear when user resets or tries a new problem

## Root Cause Analysis
Possible causes:
1. State is reset on any button click
2. Re-render clears incorrect bar state
3. Incorrect bar state not properly persisted
4. Event handlers inadvertently clear the display

## Recommended Solution
Implement persistent state for incorrect bar until explicitly cleared.

### Implementation Steps

1. **Create Persistent State**:
   ```typescript
   // In src/apps/addition/App.tsx
   
   const [incorrectAttempt, setIncorrectAttempt] = useState<{
     bars: FractionBar[];
     timestamp: number;
   } | null>(null);
   
   const [showIncorrect, setShowIncorrect] = useState(false);
   
   // When checking answer
   const checkAnswer = () => {
     if (!isCorrect()) {
       setIncorrectAttempt({
         bars: getCurrentBars(),
         timestamp: Date.now(),
       });
       setShowIncorrect(true);
       // Don't clear on other actions
     }
   };
   ```

2. **Prevent Accidental Clearing**:
   ```typescript
   // Other button handlers should NOT clear incorrect display
   const handleShowMixedFraction = () => {
     setShowMixed(!showMixed);
     // DON'T do: setShowIncorrect(false);
     // Incorrect bar should persist
   };
   
   const handleShowNumberLine = () => {
     setShowNumberLine(!showNumberLine);
     // DON'T do: setShowIncorrect(false);
   };
   
   const handleOtherActions = () => {
     // Other actions...
     // Incorrect bar remains visible
   };
   ```

3. **Explicit Clear Only**:
   ```typescript
   // Only clear incorrect bar when:
   // 1. User clicks "try again" or "reset"
   // 2. User starts a new problem
   // 3. User clicks "close" on incorrect bar
   
   const clearIncorrect = () => {
     setIncorrectAttempt(null);
     setShowIncorrect(false);
   };
   
   const resetProblem = () => {
     clearIncorrect();
     // Reset other state...
   };
   
   const newProblem = () => {
     clearIncorrect();
     // Generate new problem...
   };
   ```

4. **Add Close Button to Incorrect Bar**:
   ```tsx
   {showIncorrect && incorrectAttempt && (
     <div className="incorrect-bar-display">
       <button 
         className="close-incorrect"
         onClick={clearIncorrect}
         aria-label="關閉錯誤提示"
       >
         ✕
       </button>
       <div className="incorrect-label">錯誤示範：</div>
       {incorrectAttempt.bars.map((bar, i) => (
         <FractionBar key={i} {...bar} isIncorrect />
       ))}
     </div>
   )}
   ```

5. **Persist Across Re-renders**:
   ```typescript
   // Use useRef if needed for extra persistence
   const incorrectBarRef = useRef<HTMLDivElement>(null);
   
   // Or use localStorage for session persistence
   useEffect(() => {
     if (incorrectAttempt) {
       localStorage.setItem('lastIncorrect', JSON.stringify(incorrectAttempt));
     }
   }, [incorrectAttempt]);
   ```

## State Management Logic
```typescript
// Clear incorrect bar when:
clearIncorrect() when:
  - User clicks "重新開始" (reset)
  - User clicks "下一題" (next problem)
  - User clicks close (✕) on incorrect bar
  - User gets correct answer

// Keep incorrect bar when:
persist() when:
  - Toggling display options (mixed fraction, number line)
  - Changing animation speed
  - Any other UI interaction
  - Re-rendering components
```
