# Fix 003: Square Corners for All Bar Charts

## Problem Description
All fraction bar charts (長條圖) should use square corners instead of rounded corners for consistency and clarity.

## Design Reference
- UI reference: 「異分母分數加法」 (addition app)
- Functionality reference: 「整數與分數互換」 (intfracconv app)

## Current State
- Some bar charts have rounded corners
- Inconsistent styling across different apps

## Affected Files
All apps with fraction bars:
- `src/shared/components/FractionBar.tsx`
- `src/shared/components/InteractiveBars.tsx`
- `src/shared/base.css`
- `src/apps/addition/app.css`
- `src/apps/subtraction/app.css`
- `src/apps/multiplication/app.css`
- `src/apps/division/app.css`
- `src/apps/comparison/app.css`
- `src/apps/equivalent/app.css`
- `src/apps/expanding/app.css`
- `src/apps/intfracconv/app.css`

## Proposed Solution

### 1. Update Base FractionBar Component
Remove border-radius from all fraction bar elements

### 2. Create Consistent Styling
Define square corner style in base.css and apply globally

### 3. Verify Visual Consistency
Ensure all apps use the same bar chart style

## Implementation Steps

1. **Update base CSS**
   ```css
   /* In src/shared/base.css */
   .fraction-bar,
   .fraction-segment,
   .interactive-bar {
     border-radius: 0 !important;
   }
   ```

2. **Update FractionBar component**
   - Remove any inline border-radius styles
   - Remove border-radius from styled components
   - Ensure container divs also have square corners

3. **Update app-specific styles**
   - Check each app's app.css for border-radius overrides
   - Remove or set to 0

4. **Update number line bars**
   - Ensure number line segments also have square corners
   - Check both filled and empty segments

5. **Update interactive elements**
   - Draggable bars should have square corners
   - Drop zones should have square corners
   - Trash bin display bars should have square corners

## Code Changes

### src/shared/components/FractionBar.tsx
```typescript
// Remove any border-radius from inline styles
const barStyle = {
  width: `${width}%`,
  height: '100%',
  backgroundColor: color,
  // Remove: borderRadius: '4px'
};
```

### src/shared/base.css
```css
/* Add global override */
.fraction-bar-container,
.fraction-bar-segment,
.number-line-segment,
.interactive-bar-segment {
  border-radius: 0 !important;
}

/* Ensure outer containers are also square */
.fraction-bar-wrapper {
  border-radius: 0;
  overflow: hidden;
}
```
