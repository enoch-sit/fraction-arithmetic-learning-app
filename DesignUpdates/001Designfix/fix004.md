# Fix 004: Add Horizontal Line at 1/3 Height in IntFracConv Bar Chart

## Problem Description
The app 「整數與分數互換」 should have a horizontal line in the bar chart at approximately 1/3 height.

## Reference Image
![Image 5](images/image_5.png)

## Current State
- Bar chart exists but lacks the horizontal reference line
- Line should help users visualize fractional parts

## Affected Files
- `src/apps/intfracconv/App.tsx`
- `src/apps/intfracconv/app.css`
- `src/shared/components/FractionBar.tsx` (if reused component)

## Proposed Solution

### 1. Add Horizontal Divider Line
Add a visual line element positioned at 1/3 of the bar height

### 2. Make it Configurable
Allow the line position to be set dynamically (in case 1/3 isn't always appropriate)

### 3. Style Appropriately
Line should be subtle but visible - thin, dashed or solid line

## Implementation Steps

1. **Determine exact positioning**
   - Line at 33.333% from top (1/3 height)
   - Should span full width of bar chart
   - Should be visible across all segments

2. **Add line element to component**
   ```tsx
   // In intfracconv/App.tsx or FractionBar component
   <div className="fraction-bar-container" style={{ position: 'relative' }}>
     <div className="fraction-bar-reference-line" />
     {/* existing bar segments */}
   </div>
   ```

3. **Style the line**
   ```css
   /* In intfracconv/app.css */
   .fraction-bar-reference-line {
     position: absolute;
     top: 33.333%;
     left: 0;
     right: 0;
     height: 2px;
     background-color: rgba(0, 0, 0, 0.3);
     z-index: 10;
     pointer-events: none;
   }
   
   /* Alternative: dashed line */
   .fraction-bar-reference-line {
     border-top: 2px dashed rgba(0, 0, 0, 0.3);
   }
   ```

4. **Ensure line visibility**
   - Set appropriate z-index above bar segments but below interaction elements
   - Use contrasting color that works with both filled and empty segments
   - Test with different fraction values

5. **Make responsive**
   - Line should maintain position across different screen sizes
   - Should work in both tablet and mobile layouts

## Design Considerations

### Line Style Options:
1. **Solid thin line** - Simple, always visible
2. **Dashed line** - Less intrusive, clear reference
3. **Dotted line** - Subtle, minimal

**Recommended**: Dashed line with subtle color (rgba(0, 0, 0, 0.3))

### Color Options:
- Gray (#999999) - Neutral, works with most colors
- Black with opacity - Simple and clear
- Theme-based - Match app color scheme

## Code Example

```tsx
// In src/apps/intfracconv/App.tsx

const FractionBarWithLine = ({ numerator, denominator, color }) => {

```
