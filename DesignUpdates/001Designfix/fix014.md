# Fix 014: Incorrect Bar Should Display After Dragging Without Common Denominator

## Problem
In the app 「異分母分數減法」, the 'incorrect bar' should display after dragging the fraction bar above without getting the common denominator.

## Affected Apps
- Subtraction (異分母分數減法)

## Current State
When user drags fraction bars without first converting to common denominator:
- No visual feedback is shown
- User doesn't understand why the action is incorrect
- Missing educational opportunity to show the error

## Expected Behavior
- User drags bars with different denominators
- System detects this is incorrect approach
- Display "incorrect bar" showing what went wrong
- Provide feedback that common denominator is needed first

## Educational Purpose
Help students understand:
- Cannot directly subtract fractions with different denominators
- Must find common denominator first
- Show visual mismatch between different denominator bars

## Recommended Solution
Implement validation and visual feedback when attempting subtraction without common denominator.

### Implementation Steps

1. **Add Drag Validation**:
   ```typescript
   // In src/apps/subtraction/App.tsx
   
   const onBarDrag = (bar: FractionBar, dropZone: string) => {
     const [frac1, frac2] = currentFractions;
     
     // Check if denominators are same
     if (frac1.denominator !== frac2.denominator) {
       // Show incorrect feedback
       setIncorrectAttempt({
         type: 'different-denominators',
         bars: [frac1, frac2],
         message: '分母不同，需要先通分！',
       });
       setShowIncorrect(true);
       
       // Optionally prevent the drop
       return false; // Or allow drop but show as incorrect
     }
     
     // Continue with valid subtraction
     return true;
   };
   ```

2. **Render Incorrect Bar Display**:

4. **Add Conversion Helper**:
   ```typescript
   const handleShowCommonDenomHelp = () => {
     setShowConversionHelper(true);
     // Show step-by-step guide to find common denominator
     showGuidedConversion(frac1, frac2);
   };
   
   const showGuidedConversion = (f1: Fraction, f2: Fraction) => {
     const lcd = findLCM(f1.denominator, f2.denominator);
     
     setConversionSteps([
       {
         title: '第一步：找出最小公倍數',
         content: `${f1.denominator} 和 ${f2.denominator} 的最小公倍數是 ${lcd}`,
       },
       {
         title: '第二步：擴分第一個分數',
         content: `${f1.numerator}/${f1.denominator} = ${f1.numerator * (lcd / f1.denominator)}/${lcd}`,
       },
       {
         title: '第三步：擴分第二個分數',
         content: `${f2.numerator}/${f2.denominator} = ${f2.numerator * (lcd / f2.denominator)}/${lcd}`,
       },
       {
         title: '現在可以減法了！',
         content: '兩個分數現在有相同的分母',
       },
     ]);
   };
   ```
