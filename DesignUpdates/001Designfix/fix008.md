# Fix 008: Missing Up/Down Arrows After Clicking 「顯示帶分數」

## Problem
In the apps 「異分母分數加法」,「異分母分數減法」,「分數乘法教學」,「異分母分數除法」, after clicking the button 「顯示帶分數」, the input box does not have up and down arrows.

## Affected Apps
- Addition (異分母分數加法)
- Subtraction (異分母分數減法)
- Multiplication (分數乘法教學)
- Division (異分母分數除法)

## Current State
When switching to mixed fraction (帶分數) display mode:
- Input boxes lose their stepper arrows
- Users can only type values, cannot use increment/decrement
- Inconsistent with initial state

## Root Cause Analysis
Possible causes:
1. Input type changes from "number" to "text"
2. FracInputStepper component not rendering in mixed fraction mode
3. Conditional rendering removes stepper component
4. CSS display: none on stepper buttons
5. Component re-renders without stepper props

## Recommended Solution
Ensure stepper arrows remain visible and functional in mixed fraction mode.

### Implementation Steps

1. **Review FracInputStepper Component**:
   ```typescript
   // In src/shared/components/FracInputStepper.tsx
   // Ensure component always renders arrows
   
   interface FracInputStepperProps {
     value: number;
     onChange: (value: number) => void;
     min?: number;
     max?: number;
     disabled?: boolean;
     showMixedFraction?: boolean; // Add if needed
   }
   
   export const FracInputStepper: React.FC<FracInputStepperProps> = ({
     value,
     onChange,
     min = 0,
     max = 99,
     disabled = false,
     showMixedFraction = false, // Should not affect stepper
   }) => {
     return (
       <div className="frac-input-stepper">
         <input 
           type="number"
           value={value}
           onChange={(e) => onChange(parseInt(e.target.value) || 0)}
           min={min}
           max={max}
           disabled={disabled}
         />
         <div className="stepper-buttons">
           <button 
             className="stepper-up"
             onClick={() => onChange(Math.min(value + 1, max))}
             disabled={disabled || value >= max}
           >
             ▲
           </button>
           <button 
             className="stepper-down"
             onClick={() => onChange(Math.max(value - 1, min))}
             disabled={disabled || value <= min}
           >
             ▼
           </button>
         </div>
       </div>
     );
   };
   ```

2. **Check Conditional Rendering**:
   ```typescript
   // In affected app components
   // BAD - removes stepper
   {showMixedFraction ? (
     <input type="text" value={value} />
   ) : (
     <FracInputStepper value={value} onChange={setValue} />
   )}
   
   // GOOD - keeps stepper
   <FracInputStepper 
     value={value} 
     onChange={setValue}
     showMixedFraction={showMixedFraction}
   />
   ```

3. **Verify CSS Doesn't Hide Arrows**:
   ```css
   /* Ensure arrows are always visible */
   .frac-input-stepper .stepper-buttons {
     display: flex !important;
     flex-direction: column;
   }
   
   .frac-input-stepper button {
     display: block !important;
     pointer-events: auto;
   }
   
   /* Don't hide in mixed fraction mode */
   .mixed-fraction-mode .stepper-buttons {
     display: flex !important; /* Override any hiding */
   }
   ```

4. **Ensure Native HTML5 Input Arrows**:
   ```css
   /* Keep browser's native number input arrows */
   input[type="number"]::-webkit-inner-spin-button,
   input[type="number"]::-webkit-outer-spin-button {
     opacity: 1;
     height: 20px;
   }
   ```
