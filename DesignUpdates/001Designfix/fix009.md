# Fix 009: Incorrect Bar Has Overlap Issues in Addition App

## Problem
The app 「異分母分數加法」 has an 'incorrect bar' with overlap issues.

## Affected Apps
- Addition (異分母分數加法)

## Current State
When displaying an incorrect answer or incorrect bar visualization:
- Bars overlap with each other
- Visual elements collide
- Difficult to see individual bars clearly

## Root Cause Analysis
Possible causes:
1. Z-index conflicts between bars
2. Absolute positioning overlap
3. Missing margin/padding between bars
4. Transform animations causing overlap
5. Flex/grid layout issue

## Recommended Solution
Fix the positioning and layering of incorrect bars to prevent overlap.

1. **Identify Incorrect Bar Rendering**:
   ```typescript
   // Find where incorrect bar is rendered
   ```

   ```css
   /* In src/apps/addition/app.css */
   ```
