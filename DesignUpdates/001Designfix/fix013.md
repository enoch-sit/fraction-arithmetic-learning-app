# Fix 013: Number Line Display Error in Subtraction App

## Problem
In the app 「異分母分數減法」, the display of 數線 (number line) has an error.

## Reference
![Image 7](images/image_7.png)

## Affected Apps
- Subtraction (異分母分數減法)

## Current State
The number line (數線) displays incorrectly:
- Wrong scale or positioning
- Incorrect fraction markers
- Visual alignment issues
- Segments not displaying properly

## Root Cause Analysis
Possible causes:
1. SVG path calculations incorrect
2. Scale mapping wrong (fraction to pixels)
3. Segment boundaries miscalculated
4. Zero point or unit length incorrect
5. Responsive sizing causing misalignment

## Recommended Solution
Fix the number line rendering to display fractions correctly on the scale.

### Implementation Steps

1. **Review Number Line Component**:
   ```typescript
   // Check src/shared/components/NumberLine.tsx or similar
   // Or in src/apps/subtraction/App.tsx if inline
   
   interface NumberLineProps {
     start: number;      // Usually 0
     end: number;        // Usually 1 or 2
     fractions: Fraction[];
     highlightValue?: number;
   }
   ```

2. **Fix Scale Calculation**:
   ```typescript
   const NumberLine: React.FC<NumberLineProps> = ({ 
     start = 0, 
     end = 2, 
     fractions 
   }) => {
     const width = 800; // SVG width
     const markerHeight = 40;
     
     // Convert fraction to x-position
     const fractionToX = (numerator: number, denominator: number) => {
       const value = numerator / denominator;
       return (value - start) / (end - start) * width;
     };
     
     return (
       <svg width={width} height={markerHeight + 40} className="number-line">
         {/* Main line */}
         <line 
           x1={0} 
           y1={markerHeight} 
           x2={width} 
           y2={markerHeight}
           stroke="black"
           strokeWidth={2}
         />
         
         {/* Start and end markers */}
         <g>
           <line x1={0} y1={markerHeight - 10} x2={0} y2={markerHeight + 10} 
                 stroke="black" strokeWidth={2} />
           <text x={0} y={markerHeight + 25} textAnchor="middle">{start}</text>
         </g>
         <g>
           <line x1={width} y1={markerHeight - 10} x2={width} y2={markerHeight + 10} 
                 stroke="black" strokeWidth={2} />
           <text x={width} y={markerHeight + 25} textAnchor="middle">{end}</text>
         </g>
         
         {/* Fraction markers */}
         {fractions.map((frac, i) => {
           const x = fractionToX(frac.numerator, frac.denominator);
           return (
             <g key={i}>
               <line 
                 x1={x} 
                 y1={markerHeight - 15} 
                 x2={x} 
                 y2={markerHeight + 15}
                 stroke={frac.color || 'blue'}
                 strokeWidth={2}
               />
               <text 
                 x={x} 
                 y={markerHeight - 20} 
                 textAnchor="middle"
                 fill={frac.color || 'blue'}
               >
                 {frac.numerator}/{frac.denominator}
               </text>
             </g>
           );
         })}
       </svg>
     );
   };
   ```

3. **Fix Common Denominator Display**:
   ```typescript
   // For subtraction, show divisions based on common denominator
   const renderSubdivisions = (commonDenom: number) => {
     const subdivisions = [];
     for (let i = 0; i <= commonDenom; i++) {
       const x = (i / commonDenom) * width;
       subdivisions.push(
         <line 
           key={i}
           x1={x} 
           y1={markerHeight - 5} 
           x2={x} 
           y2={markerHeight + 5}
           stroke="#ccc"
           strokeWidth={1}
         />
       );
     }
     return subdivisions;
   };
   ```

4. **Handle Edge Cases**:
   ```typescript
   // Ensure fractions are in valid range
   const clampFraction = (num: number, denom: number, max: number) => {
     const value = num / denom;
     if (value < 0) return { numerator: 0, denominator: denom };
     if (value > max) return { numerator: max * denom, denominator: denom };
     return { numerator: num, denominator: denom };
   };
   ```
