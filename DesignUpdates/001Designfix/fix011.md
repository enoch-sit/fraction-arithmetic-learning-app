# Fix 011: Incorrect Display Location for「拖到這裡」Tooltip

## Problem
In the app 「異分母分數加法」, tips「拖到這裡」(drag here) has incorrect display location.

## Reference
![Image 8](images/image_8.png)

## Affected Apps
- Addition (異分母分數加法)

## Current State
The tooltip or hint text「拖到這裡」appears in the wrong position:
- May be overlapping with other elements
- Not pointing to the correct drop zone
- Difficult to understand where to drag

## Root Cause Analysis
Possible causes:
1. Tooltip positioning calculation is off
2. Wrong anchor point for tooltip
3. CSS positioning issue (absolute/fixed)
4. Responsive design not adjusting position
5. Z-index or transform affecting placement

## Recommended Solution
Fix the tooltip positioning to correctly indicate the drop zone.

### Implementation Steps

1. **Identify Drop Zone**:
   ```typescript
   // In src/apps/addition/App.tsx
   <div 
     className="drop-zone"
     data-zone="result"
     ref={dropZoneRef}
   >
     {/* Drop zone content */}
   </div>
   ```

2. **Position Tooltip Correctly**:
   ```tsx
   <div className="drop-zone-container">
     <div className="drop-zone" ref={dropZoneRef}>
       {/* Drop zone */}
     </div>
     <div className="drag-hint">
       <span className="hint-icon">👆</span>
       <span className="hint-text">拖到這裡</span>
     </div>
   </div>
   ```

3. **Fix CSS Positioning**:
   ```css
   /* In src/apps/addition/app.css */
   
   .drop-zone-container {
     position: relative;
     margin: 20px 0;
   }
   
   .drag-hint {
     position: absolute;
     top: 50%;
     left: 50%;
     transform: translate(-50%, -50%);
     pointer-events: none;
     display: flex;
     align-items: center;
     gap: 8px;
     font-size: 18px;
     color: #ff9800;
     font-weight: bold;
     z-index: 5;
   }
   
   .hint-icon {
     font-size: 24px;
     animation: bounce 2s infinite;
   }
   
   @keyframes bounce {
     0%, 100% { transform: translateY(0); }
     50% { transform: translateY(-10px); }
   }
   
   /* Hide hint when dragging or when zone has content */
   .drop-zone.has-content + .drag-hint,
   .drop-zone.dragging-over + .drag-hint {
     opacity: 0.3;
   }
   ```

4. **Dynamic Positioning Based on Screen**:
   ```typescript
   const [hintPosition, setHintPosition] = useState({ top: 0, left: 0 });
   
   useEffect(() => {
     if (dropZoneRef.current) {
       const rect = dropZoneRef.current.getBoundingClientRect();
       setHintPosition({
         top: rect.top + rect.height / 2,
         left: rect.left + rect.width / 2,
       });
     }
   }, []);
   ```

5. **Ensure Visibility**:
   ```typescript
   // Show hint only when appropriate
   const shouldShowHint = !hasContent && !isDragging && showTutorial;
   
   {shouldShowHint && (
     <div className="drag-hint" style={{
       top: `${hintPosition.top}px`,
       left: `${hintPosition.left}px`,
     }}>
       👆 拖到這裡
     </div>
   )}
   ```

6. **Responsive Design**:
   ```css
   /* Mobile adjustments */
   @media (max-width: 768px) {
     .drag-hint {
       font-size: 14px;
       top: calc(50% + 20px); /* Adjust for smaller screens */
     }
     
     .hint-icon {
       font-size: 20px;
     }
   }
   ```
