# Fix 017: Missing Bar Rearranging Function in Multiplication

## Problem
In the app 「分數乘法教學」, the function of rearranging the bar is missing.

## Reference
- ![Image 2](images/image_2.png)
- ![Image 4](images/image_4.png)
- See attached file: `FractionApp45(Multiplication).html`

## Affected Apps
- Multiplication (分數乘法教學)

## Current State
Users cannot rearrange the fraction bars to visualize multiplication concepts.

## Expected Behavior
- Users should be able to click and drag bars to rearrange them
- Rearrangement helps visualize fraction multiplication
- Shows how to reorganize segments for calculation

## Educational Purpose
Rearranging bars helps students understand:
- How multiplication of fractions works visually
- How to group segments differently
- The relationship between numerator and denominator in multiplication
- Different representations of the same product

## Recommended Solution
Implement drag-and-drop functionality to rearrange fraction bar segments.

3. **Create Rearrangeable Bar Component**:
   ```tsx
   interface RearrangeableBarProps {
     bar: FractionBar;
     index: number;
     onDragStart: (index: number) => void;
     onDragOver: (index: number) => void;
     onDrop: (index: number) => void;
   }
   
   const RearrangeableBar: React.FC<RearrangeableBarProps> = ({
     bar,
     index,
     onDragStart,
     onDragOver,
     onDrop,
   }) => {
     return (
       <div
         className="rearrangeable-bar"
         draggable={true}
         onDragStart={() => onDragStart(index)}
         onDragOver={(e) => {
           e.preventDefault();
           onDragOver(index);
         }}
         onDrop={() => onDrop(index)}
       >
         <div className="drag-handle">⋮⋮</div>
         <FractionBar {...bar} />
         <div className="bar-label">
           {bar.numerator}/{bar.denominator}
         </div>
       </div>
     );
   };
   ```

4. **Implement Drag and Drop Logic**:
   ```typescript
   const handleDragStart = (index: number) => {
     setDraggedBarId(arrangedBars[index].id);
   };
   
   const handleDragOver = (targetIndex: number) => {
     if (!draggedBarId) return;
     
     const draggedIndex = arrangedBars.findIndex(b => b.id === draggedBarId);
     if (draggedIndex === targetIndex) return;
     
     // Reorder the bars
     const newBars = [...arrangedBars];
     const [draggedBar] = newBars.splice(draggedIndex, 1);
     newBars.splice(targetIndex, 0, draggedBar);
     
     setArrangedBars(newBars);
   };
   
   const handleDrop = (targetIndex: number) => {
     setDraggedBarId(null);
   };
   ```
