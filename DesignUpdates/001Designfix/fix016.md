# Fix 016: Incorrect Trash Bin Display in Subtraction

## Problem
In the app 「異分母分數減法」, the display in trash bin is incorrect. The length of each section of the bar chart should be equal, and it should show two bars.

## Reference
![Image 1](images/image_1.png)
The image shows comparison: left is github version, right is original HTML.

## Reference File
See attached: `FractionApp48(Subtraction).html`

## Affected Apps
- Subtraction (異分母分數減法)

## Current State
When bars are placed in trash bin:
- Section lengths are unequal (should be equal)
- May show only one bar instead of two
- Visual representation doesn't match original design

## Expected Behavior
Trash bin should display:
- Two bars (for both fractions being removed)
- Equal segment lengths across all sections
- Consistent with original HTML version

## Root Cause Analysis
Possible causes:
1. Trash bin uses different rendering logic than main display
2. Segment width calculation is wrong
3. Common denominator not applied in trash display
4. CSS flexbox/grid not distributing space equally
5. Bars are merged instead of shown separately

## Recommended Solution
Fix trash bin rendering to show two separate bars with equal segment lengths.

### Implementation Steps

1. **Review Trash Bin Rendering**:
   ```typescript
   // In src/apps/subtraction/App.tsx
   
   interface TrashedBar {
     id: string;
     numerator: number;
     denominator: number;

     return (

   ```

2. **Fix FractionBar Equal Segments**:
   ```typescript
   // In src/shared/components/FractionBar.tsx
   
   interface FractionBarProps {
     numerator: number;
     denominator: number;
     color?: string;
     equalSegments?: boolean; // New prop
   }
   
   const FractionBar: React.FC<FractionBarProps> = ({
     numerator,
     denominator,
     color = '#4CAF50',
     equalSegments = false,
   }) => {
     return (
       <div className="fraction-bar-container">
         {Array.from({ length: denominator }).map((_, i) => {
           const isFilled = i < numerator;
           return (
             <div
               key={i}
               className="fraction-segment"
               style={{
                 flex: equalSegments ? `1 1 ${100 / denominator}%` : '1',
                 width: equalSegments ? `${100 / denominator}%` : 'auto',
                 backgroundColor: isFilled ? color : 'transparent',
                 border: '1px solid #333',
               }}
             />
           );
         })}
       </div>
     );
   };
   ```

3. **Ensure Equal Width CSS**:

   const renderEqualSegments = (
     totalSegments: number,
     filledSegments: number,
     color: string

     return (
       <div className="segment-container">
