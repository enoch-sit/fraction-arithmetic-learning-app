# Fix 019: UI Changes Suddenly Between Mode 1 and 2 in Comparison

## Problem
In the app 「分數比較」, there is an issue when changing between mode 1 and 2 - the whole UI changes suddenly.

## Affected Apps
- Comparison (分數比較)

## Current State
When switching between comparison modes:
- UI elements jump or shift abruptly
- Jarring visual experience
- Elements may reflow dramatically
- Disorienting for users

## Expected Behavior
Smooth transition between modes with:
- Gradual animations
- Maintained layout structure
- Elements transition smoothly
- No sudden jumps or flashes

## Root Cause Analysis
Possible causes:
1. Complete component remount on mode change
2. No transition animations
3. Different layout structures for each mode
4. Conditional rendering causing sudden changes
5. CSS classes changing without transitions

## Recommended Solution
Implement smooth transitions when switching between modes.

### Implementation Steps

1. **Identify the Two Modes**:
   ```typescript
   // In src/apps/comparison/App.tsx
   
   enum ComparisonMode {
     MODE1 = 'mode1', // e.g., side-by-side comparison
     MODE2 = 'mode2', // e.g., number line comparison
   }
   
   const [mode, setMode] = useState<ComparisonMode>(ComparisonMode.MODE1);
   ```

2. **Create Shared Layout Structure**:
   ```tsx
   // Keep consistent container structure
   <div className="comparison-app">
     <div className="mode-selector">
       <button 
         className={mode === ComparisonMode.MODE1 ? 'active' : ''}
         onClick={() => setMode(ComparisonMode.MODE1)}
       >
         模式1: 並排比較
       </button>
       <button 
         className={mode === ComparisonMode.MODE2 ? 'active' : ''}
         onClick={() => setMode(ComparisonMode.MODE2)}
       >
         模式2: 數線比較
       </button>
     </div>
     
     <div className={`comparison-workspace mode-${mode}`}>
       {/* Shared container for both modes */}
       <div className="fractions-display">
         {renderModeContent()}
       </div>
     </div>
   </div>
   ```

3. **Add CSS Transitions**:
   ```css
   /* In src/apps/comparison/app.css */
   
   .comparison-workspace {
     transition: all 0.3s ease-in-out;
     min-height: 400px; /* Prevent height jumping */
   }
   
   .fractions-display {
     transition: opacity 0.3s, transform 0.3s;
   }
   
   /* Fade out old mode */
   .comparison-workspace.transitioning-out .fractions-display {
     opacity: 0;
     transform: scale(0.95);
   }
   
   /* Fade in new mode */
   .comparison-workspace.transitioning-in .fractions-display {
     opacity: 0;
     transform: scale(1.05);
     animation: fadeIn 0.3s forwards;
   }
   
   @keyframes fadeIn {
     to {
       opacity: 1;
       transform: scale(1);
     }
   }
   
   /* Mode-specific layouts */
   .comparison-workspace.mode-mode1 .fractions-display {
     display: flex;
     justify-content: space-around;
   }
   
   .comparison-workspace.mode-mode2 .fractions-display {
     display: flex;
     flex-direction: column;
     align-items: center;
   }
   ```

4. **Implement Transition State**:
   ```typescript
   const [isTransitioning, setIsTransitioning] = useState(false);
   
   const changeMode = (newMode: ComparisonMode) => {
     if (newMode === mode) return;
     
     setIsTransitioning(true);
     
     // Fade out current content
     setTimeout(() => {
       setMode(newMode);
       
       // Fade in new content
       setTimeout(() => {
         setIsTransitioning(false);
       }, 50);
     }, 300);
   };
   ```

5. **Use Transition Component** (if using React):
   ```tsx
   import { CSSTransition, SwitchTransition } from 'react-transition-group';
   
   <SwitchTransition mode="out-in">
     <CSSTransition
       key={mode}
       timeout={300}
       classNames="mode-transition"
     >
       <div className="mode-content">
         {mode === ComparisonMode.MODE1 ? (
           <Mode1Display fractions={fractions} />
         ) : (
           <Mode2Display fractions={fractions} />
         )}
       </div>
     </CSSTransition>
   </SwitchTransition>
   
   /* CSS */
   .mode-transition-enter {
     opacity: 0;
     transform: translateX(20px);
   }
   
   .mode-transition-enter-active {
     opacity: 1;
     transform: translateX(0);
     transition: opacity 300ms, transform 300ms;
   }
   
   .mode-transition-exit {
     opacity: 1;
     transform: translateX(0);
   }
   
   .mode-transition-exit-active {
     opacity: 0;
     transform: translateX(-20px);
     transition: opacity 300ms, transform 300ms;
   }
   ```

6. **Maintain Fixed Dimensions**:
   ```css
   /* Prevent layout shifts */
   .comparison-workspace {
     min-height: 500px;
     position: relative;
   }
   
   .mode-content {
     position: absolute;
     top: 0;
     left: 0;
     right: 0;
     width: 100%;
   }
   
   /* Or use min-height approach */
   .fractions-display {
     min-height: 300px;
     display: flex;
     align-items: center;
     justify-content: center;
   }
   ```

7. **Smooth Mode Indicator**:
   ```tsx
   <div className="mode-indicator">
     <div 
       className="indicator-slider"
       style={{
         transform: `translateX(${mode === ComparisonMode.MODE1 ? '0' : '100%'})`,
       }}
     />
   </div>
   
   /* CSS */
   .mode-indicator {
     position: relative;
     background: #e0e0e0;
     border-radius: 20px;
     padding: 4px;
     display: flex;
     gap: 4px;
   }
   
   .indicator-slider {
     position: absolute;
     top: 4px;
     left: 4px;
     width: calc(50% - 4px);
     height: calc(100% - 8px);
     background: #2196F3;
     border-radius: 16px;
     transition: transform 0.3s ease;
   }
   ```

8. **Preserve State Between Modes**:
   ```typescript
   // Keep fraction data consistent across modes
   const [fractions, setFractions] = useState<Fraction[]>([]);
   const [userSelection, setUserSelection] = useState<string[]>([]);
   
   // Don't reset state on mode change
   const changeMode = (newMode: ComparisonMode) => {
     // Preserve fractions and user progress
     setMode(newMode);
     // Don't call setFractions([]) or setUserSelection([])
   };
   ```
