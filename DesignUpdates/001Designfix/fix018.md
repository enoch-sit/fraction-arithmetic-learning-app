# Fix 018: Delete「目前排序」in Comparison App

## Problem
In the app 「分數比較」, delete「目前排序」(current sorting), as it directly shows the answer to students.

## Affected Apps
- Comparison (分數比較)

## Current State
- The "current sorting" display shows the correct order
- Students can see the answer without working through the problem
- Defeats the educational purpose

## Educational Issue
Showing「目前排序」:
- Reveals the solution immediately
- Removes the learning challenge
- Students don't practice comparison skills
- No opportunity for trial and error

## Recommended Solution
Remove the「目前排序」display that shows the correct answer.
