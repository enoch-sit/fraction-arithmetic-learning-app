# Fix 006: Add Tutorial/Guided Tour to IntFracConv App

## Problem Description
The app 「整數與分數互換」 does not include a tutorial setting or guided tour, unlike other apps in the suite.

## Current State
- IntFracConv app lacks tutorial functionality
- Other apps (addition, subtraction, etc.) have guided tours
- New users have no guidance on how to use the app

## Affected Files
- `src/apps/intfracconv/App.tsx`
- Create: `src/shared/guides/intfracconv-guide.ts` or similar
- `src/shared/components/GuidedTour.tsx` (existing component)

## Reference
- Check existing guided tours in other apps:
  - `src/apps/addition/App.tsx`
  - `src/apps/subtraction/App.tsx`
  - `src/shared/tours/` directory

## Proposed Solution

### 1. Create Tutorial Content
Define step-by-step guide for IntFracConv features

### 2. Integrate GuidedTour Component
Add existing GuidedTour component to IntFracConv app

### 3. Add Tutorial Toggle
Add checkbox or button to enable/disable tutorial

### 4. Define Tutorial Steps
Create steps covering all main features

3. **Add GuidedTour to IntFracConv**
   ```tsx
   // In src/apps/intfracconv/App.tsx
   import { GuidedTour } from '@/shared/components/GuidedTour';
   import { intFracConvTourSteps } from '@/shared/guides/intfracconv-guide';
   
   function IntFracConvApp() {
     const [showTutorial, setShowTutorial] = useState(true);
     const [currentStep, setCurrentStep] = useState(0);
     
     return (
       <div>
         {/* Tutorial toggle */}
         <label>
           <input 
             type="checkbox"
             checked={showTutorial}
             onChange={(e) => setShowTutorial(e.target.checked)}
           />
           顯示教學
         </label>
         
         {/* Rest of app */}
         <div className="app-content">
           {/* ... */}
         </div>
         
         {/* Guided tour */}
         {showTutorial && (
           <GuidedTour 
             steps={intFracConvTourSteps}
             currentStep={currentStep}
             onStepChange={setCurrentStep}
             onComplete={() => setShowTutorial(false)}
           />
         )}
       </div>
     );
   }
   ```

4. **Add CSS classes for targeting**
   Ensure all tutorial targets have appropriate class names:
   ```tsx

   <div className="reference-line">...</div>
   <div className="conversion-display">...</div>
   ```

5. **Store tutorial preference**
   ```typescript
   // Save user preference
   useEffect(() => {
     const savedPref = localStorage.getItem('intfracconv-tutorial');
     if (savedPref !== null) {
       setShowTutorial(savedPref === 'true');
     }
   }, []);
   
   useEffect(() => {
     localStorage.setItem('intfracconv-tutorial', showTutorial.toString());
   }, [showTutorial]);
   ```
