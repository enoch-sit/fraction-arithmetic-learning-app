# Fix 007: Tutorial 5/5 Displays in Incorrect Location

## Problem Description
In the apps 「異分母分數加法」,「異分母分數減法」,「分數乘法教學」,「異分母分數除法」, the tutorial step 5/5 displays in the incorrect location.

## Reference Image
![Image 3](images/image_3.png)

## Current State
- Tutorial step 5/5 is mispositioned
- Overlaps with other UI elements or appears off-screen
- May be cut off or hard to read

## Affected Files
- `src/apps/addition/App.tsx`
- `src/apps/subtraction/App.tsx`
- `src/apps/multiplication/App.tsx`
- `src/apps/division/App.tsx`
- `src/shared/components/GuidedTour.tsx`
- Related CSS files for positioning

## Root Cause Analysis
Possible causes:
1. Fixed positioning not accounting for screen size
2. Z-index layering issue
3. Positioning logic doesn't handle step 5 differently
4. CSS positioning conflicts with other elements
5. Responsive design breakpoint issue

## Proposed Solution

### 1. Fix Positioning Logic
Adjust the positioning calculation for tutorial step 5

### 2. Ensure Proper Z-Index
Make sure tutorial overlay is above all other elements

### 3. Add Boundary Detection
Prevent tutorial from going off-screen or overlapping critical UI

### 4. Make Responsive
Ensure tutorial position adapts to different screen sizes

## Code Example

```tsx
// In src/shared/components/GuidedTour.tsx

const GuidedTour: React.FC<GuidedTourProps> = ({ steps, currentStep, ... }) => {
  const [position, setPosition] = useState<Position>({});
  
  useEffect(() => {
    const step = steps[currentStep];
    const targetElement = document.querySelector(step.target);
    
    if (currentStep === steps.length - 1) {
      // Final step (5/5) - use fixed centered position
      setPosition({
        position: 'fixed',
        top: '50%',
        left: '50%',
        transform: 'translate(-50%, -50%)',
        zIndex: 10000
      });
    } else if (targetElement) {
      // Calculate position relative to target
      const rect = targetElement.getBoundingClientRect();
      setPosition(calculatePosition(rect, step.position));
    }
  }, [currentStep, steps]);
  
  return (
    <div 
      className={`guided-tour-popup step-${currentStep + 1}`}
      style={position}
    >
      <div className="tutorial-header">
        <span className="step-indicator">{currentStep + 1} / {steps.length}</span>
        <button onClick={onClose}>✕</button>
      </div>
      <div className="tutorial-content">
        <h3>{steps[currentStep].title}</h3>
        <p>{steps[currentStep].content}</p>
      </div>
      <div className="tutorial-actions">
        {currentStep > 0 && (
          <button onClick={onPrevious}>← 上一步</button>
        )}
        {currentStep < steps.length - 1 ? (
          <button onClick={onNext}>下一步 →</button>
        ) : (
          <button onClick={onComplete}>完成 ✓</button>
        )}
      </div>
    </div>
  );
};
```
