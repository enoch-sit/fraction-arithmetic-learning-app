# Fix 015: Trash Bin Should Display When Both Fraction Bars Are Displayed

## Problem
In the app 「異分母分數減法」, the trash bin should be displayed when both fraction bars are displayed.

## Reference
![Image 6](images/image_6.png)

## Affected Apps
- Subtraction (異分母分數減法)

## Current State
- Trash bin icon/area may not appear at the right time
- Should show when both bars are visible for removal/reset

## Expected Behavior
- When both fraction bars are displayed on screen
- Show trash bin icon or drop zone
- Allow users to drag incorrect bars to trash
- Provide way to reset/remove bars

## Purpose
- Allow users to remove incorrect attempts
- Provide clear reset mechanism
- Enable trying different approaches

## Recommended Solution
Display trash bin zone when both fraction bars are visible.

### Implementation Steps

1. **Add Trash Bin State**:
   ```typescript
   // In src/apps/subtraction/App.tsx
   
   const [showTrashBin, setShowTrashBin] = useState(false);
   const [barsDisplayed, setBarsDisplayed] = useState<FractionBar[]>([]);
   
   useEffect(() => {
     // Show trash when both bars are visible
     if (barsDisplayed.length >= 2) {
       setShowTrashBin(true);
     } else {
       setShowTrashBin(false);
     }
   }, [barsDisplayed]);
   ```

2. **Render Trash Bin Component**:
   ```tsx
   {showTrashBin && (
     <div 
       className="trash-bin-zone"
       onDragOver={handleDragOver}
       onDrop={handleDropToTrash}
     >
       <div className="trash-icon">
         🗑️
       </div>
       <div className="trash-label">
         拖到這裡刪除
       </div>
       {trashContents.length > 0 && (
         <div className="trash-contents">
           <p>垃圾桶內容:</p>
           {trashContents.map((item, i) => (
             <div key={i} className="trashed-item">
               {item.numerator}/{item.denominator}
             </div>
           ))}
         </div>
       )}
     </div>
   )}
   ```

3. **Handle Trash Drop**:
   ```typescript
   const handleDropToTrash = (e: React.DragEvent) => {
     e.preventDefault();
     const barId = e.dataTransfer.getData('barId');
     
     // Find and remove the bar
     const barToRemove = barsDisplayed.find(b => b.id === barId);
     if (barToRemove) {
       // Add to trash contents for display
       setTrashContents(prev => [...prev, barToRemove]);
       
       // Remove from displayed bars
       setBarsDisplayed(prev => prev.filter(b => b.id !== barId));
       
       // Show confirmation
       showNotification('已移至垃圾桶');
     }
   };
   
   const handleDragOver = (e: React.DragEvent) => {
     e.preventDefault();
     e.dataTransfer.dropEffect = 'move';
   };
   ```

5. **Add Empty Trash Option**:
   ```tsx
   {trashContents.length > 0 && (
     <button 
       className="empty-trash"
       onClick={() => {
         setTrashContents([]);
         showNotification('垃圾桶已清空');
       }}
       title="清空垃圾桶"
     >
       清空
     </button>
   )}
   ```

6. **Add Visual Feedback**:
   ```typescript
   // Highlight trash bin when dragging
   const [isDraggingBar, setIsDraggingBar] = useState(false);
   
   const onBarDragStart = (barId: string) => {
     setIsDraggingBar(true);
   };
   
   const onBarDragEnd = () => {
     setIsDraggingBar(false);
   };
   
   <div className={`trash-bin-zone ${isDraggingBar ? 'active' : ''}`}>
   ```

7. **Make Bars Draggable to Trash**:
   ```tsx
   <div
     className="fraction-bar"
     draggable={true}
     onDragStart={(e) => {
       e.dataTransfer.setData('barId', bar.id);
       onBarDragStart(bar.id);
     }}
     onDragEnd={onBarDragEnd}
   >
     <FractionBar {...bar} />
   </div>
   ```
