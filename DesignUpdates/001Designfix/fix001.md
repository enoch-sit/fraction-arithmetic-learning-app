# Fix 001: Duplicate Apps - Remove or Consolidate

## Problem Description
The apps 「分數擴分與約分」 (expanding) and 「相等分數(約分/擴分)」 (equivalent) are the same functionality. 
- Latest version: 「相等分數(約分/擴分)」
- Need to decide: keep both or only one?

## Current State
- Two apps exist with duplicate functionality
- Confusing for users to have both options
- 「相等分數(約分/擴分)」 is the latest version

## Affected Files
- `src/apps/expanding/` - Older version
- `src/apps/equivalent/` - Latest version
- `expanding.html` - Entry point for old version
- `equivalent.html` - Entry point for new version
- `index.html` - Main hub that links to both apps

## Proposed Solution

### Option 1: Keep Only Latest Version (Recommended)
1. Remove the `expanding` app entirely
2. Update index.html to remove link to expanding app
3. Update navigation/documentation to reference only equivalent app

### Option 2: Keep Both with Clear Differentiation
1. Rename apps to clearly show which is basic vs advanced
2. Update UI to indicate version differences
3. Add deprecation notice to older version

## Implementation Steps

### If Option 1 (Recommended):
1. **Remove old app files**
   - Delete `src/apps/expanding/` directory
   - Delete `expanding.html` entry file
   
2. **Update main hub**
   - Edit `index.html` to remove expanding app link
   - Update any navigation menus
   
3. **Update documentation**
   - Update README.md
   - Update any user guides
   
4. **Test**
   - Verify no broken links
   - Verify equivalent app works correctly
   - Check that all functionality from expanding app is present in equivalent app

## Testing Checklist
- [ ] Expanding app link removed from hub
- [ ] Equivalent app loads correctly
- [ ] No broken links in navigation
- [ ] All expanding/reducing functionality works in equivalent app
- [ ] Documentation updated

## Priority
**High** - User confusion, maintenance overhead

## Estimated Effort
2-3 hours

## Dependencies

- Coordinate with team on which option to choose
